How do I get a token?
  1. Open GitHub → New fine-grained token (sign in as the owner of the repository).
  2. Name it, and choose when it expires (for example 90 days).
  3. Repository access: “Only select repositories” → roshannandhu/9labs.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. Generate the token, copy it, and paste it above.
